# Bubble implementation contract

The latest September 5, 2026 request expands foreground compatibility to ALL browser web tabs/frames and adds long-press navigation/tab menus plus local ChatGPT tools. Read docs/FLOATING_V060.md, docs/MOTION_AND_ALERTS_V061.md, docs/LIVE_TOOLS_V070.md and docs/VALIDATION_STATUS.md. New explicit requirements supersede the former ChatGPT-only foreground shim scope, NOT the exact-origin native reply-monitor boundary.

Preserve debug signing identity, package, app-private profile, UUID tabs and compatible workspace store. No browser bootstrap in Application or Gecko subprocesses. Gecko operations stay main-thread; disk IO off-main-thread. One runtime and exactly one display owner per GeckoSession. Fullscreen uses SurfaceView; interactive floating uses TextureView for clipping. One foreground service owns bubble/chooser/chat or notification-parked state. Preserve drag-to-X, restore route, input, native PiP, existing motion and substantive regression assertions. Never make stored data dismiss an Activity. User permission/file flows are not Home actions.

Open tabs have no arbitrary logical cap. Every retained session remains active/high-priority; native input focus is exclusive. The MAIN-world foreground script matches ordinary http/https documents and browser-authorized child frames at document_start; it exposes no native API, performs no networking and does not fake trusted user activation, idle hardware state or permissions. The isolated native reply monitor remains EXACT https://chatgpt.com, top-frame, session-validated. No TLS bypass, analytics, fake gestures or blanket permission grants. JavaScript compatibility is detectable and cannot guarantee survival after Doze/force-stop/process reclamation. Never claim undetectability or certified never-suspend behavior.

Quick menus work from both Activity and overlay and remain bounded, dismissible and keyboard-aware. Long-press Back must work even with empty back history. Local names, pins, notes, prompts and closed-tab history stay in app-private atomic storage. Closing a tab never deletes a server conversation. Duplicate means another tab at the same URL, not a ChatGPT branch. Prompt templates are copied only on an explicit user command and are never auto-sent. Closed-history retention is 20; that is not an open-tab cap.

Do not claim successful runtime tests from compilation or 120fps from refresh requests. Run actual input, page-start presence, cross-origin-frame, popup, floating, notification, persistence and compositor tests. Record authentic device/performance limitations and actual failures. Keep meaningful interruptible motion; do not stretch webpage text, add idle loops or permanently bitmap-cache the page.
