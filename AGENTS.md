# Bubble implementation contract

The user requested a clean rewrite, interactive floating chat, tab selection from a bubble, native PiP, Home/Back minimization, compact animated UI, then drag-to-notification hiding and thoughtful motion/ChatGPT alerts on September 5, 2026. Read `docs/FLOATING_V060.md`, `docs/MOTION_AND_ALERTS_V061.md` and `docs/VALIDATION_STATUS.md` for the current implementation and observed gates; these supersede older fullscreen-only head behavior.

Keep the existing debug signing identity, package and compatible workspace file. Never rotate the key as part of a fix. No production signing secrets. No browser bootstrap in Application.onCreate or Gecko subprocesses. Gecko operations are main-thread; disk IO is off-main-thread. One process runtime owns durable UUID tabs. Each GeckoSession has exactly one display owner: fullscreen Activity or interactive floating WindowContext. Only the floating view uses TextureView for animated clipping; fullscreen retains SurfaceView. No fullscreen transparent touch-routing shim.

One compliant foreground service owns the bubble/chooser/chat or explicitly notification-parked workspace. Hiding is not closing: preserve sessions, restore route and original resting placement. The small drag target must be non-touchable and removed after drag. Refuse hiding when notifications are blocked. Minimize only through a user command or Home/Back; saved data must never dismiss an Activity. User file/permission flows are not Home actions. Native Android PiP remains separately labeled view-only.

No arbitrary logical tab cap, no voluntary suspension of retained workspace sessions. Real input focus belongs only to the selected visible view. The ChatGPT compatibility/monitor scripts are exact-origin and top-frame; no general native API is exposed. Never bypass TLS, grant arbitrary site permissions or add network analytics.

Keep purposeful, interruptible motion; never squash webpage text or force a permanent bitmap layer on Gecko. Do not call compilation a runtime proof or a display-mode request 120fps. The current full functional suite passes, but physical Pixel performance and authenticated ChatGPT completion detection remain open. Verify actual compositor pixels, input, drag/notification routing and exact session identity; record limitations and test failures honestly. Preserve every substantive test assertion when correcting a harness defect.
