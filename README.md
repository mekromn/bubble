# Bubble

Bubble is an Android web browser built around independent floating browser heads.

Each logical tab can move between normal browsing and a draggable system-overlay head without imposing an arbitrary tab-count limit. Inactive tabs are designed to be suspendable/hibernatable so logical tab capacity is not tied to the number of live WebView renderers.

## Development

Work is versioned by milestone/feature branch. The first milestone is `r01-floating-head-core`.
