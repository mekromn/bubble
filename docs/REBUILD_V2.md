# Clean rebuild contract — 2026-09-04

The user's instruction replaces the failed application implementation, not just the renderer surface. On rebuild-v2, the entire app/src tree is new native Kotlin Android code. Old history and old app data remain recoverable.

Gate 1: direct Activity-owned GeckoView; one lazy runtime; no custom Application or child-process app bootstrap. An Android 16 emulator must paint a two-colour localhost page, advance JavaScript for more than 12 seconds, and capture actual nonblank compositor pixels. Compilation/lint alone are not sufficient.

Gate 2: durable UUID tabs, retained GeckoSessions, one small acknowledged workspace overlay, native animated tab tray, async atomic snapshot persistence, bounded crash recovery, selected-session file picker, exact-origin reply signals. Instrumentation exercises multiple sessions, transitions, recreation and background/foreground.

Gate 3: public Google and ChatGPT painted documents with screenshots/titles, followed by actual Pixel 9 Pro XL authenticated ChatGPT input, streaming, multiple background generations, uploads and 120Hz frame pacing. An emulator is not a substitute for physical-device performance measurements. OS eviction/thermal/power policy and website behavior cannot be overridden by a blanket zero-jank/no-suspend claim.

The current workspace storage is new. Old Room database files are preserved, not destructively migrated. No conversation backups, prompts, cookies or private logs are committed to this repository. Runtime evidence generated by CI uses synthetic local pages or signed-out public sites only.

Keep package and original public DEBUG certificate unchanged. A separate private production key is required before release. No universal JavaScript bridge, TLS bypass, unrestricted site permission grants, analytics SDK, or fake foreground behavior.

Gate completion must be updated from observed CI reports and screenshots, not assumed from source code. User-device verification remains explicitly separate.
